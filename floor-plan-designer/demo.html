🏗️ Floor Plan Designer

A React-based web application for creating floor plans with AI-powered plant symbol placement

🎨 Drawing Tools

  • Interactive canvas with mouse drawing
  • Lines and rectangles with real-time measurements
  • Multiple drawing phases (boundary, building, walls)
  • Zoom and pan functionality
  • Object selection and dragging

📐 Precise Scaling

  • AutoCAD-compatible scaling (3.1:1, 300 DPI)
  • Accurate measurements in feet
  • A2 sheet format support
  • 1 foot = ~31.2 pixels on screen
  • Consistent coordinate mapping

🏠 Predefined Shapes

  • Plot sizes: 1 Kanal, 10 Marla, 5 Marla, Custom
  • House shapes: L-shaped, Rectangular, U-shaped
  • Smart placeholders with resizing
  • Color-coded drawing phases

🤖 AI Integration

  • YOLO CSV data import
  • Translucent plant symbol overlays
  • Coordinate-based placement
  • Category and confidence support
  • Real-time symbol updates

📤 Export Options

  • High-resolution PNG export
  • Professional PDF blueprints
  • JSON data export
  • CSV plant symbol export
  • A2 format compatibility

⚡ Technical Features

  • React 18 with TypeScript
  • Konva.js for 2D rendering
  • Styled Components for UI
  • Responsive design
  • Production-ready build

Ready to Start?

Run npm start to launch the application!

cd floor-plan-designer
npm install
npm start
